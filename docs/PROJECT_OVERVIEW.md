# Project Overview — Татьяна Золотарева, SMM Portfolio

## Описание проекта
Одностраничный лендинг-портфолио для Татьяны Золотаревой — SMM-специалиста в нише домашнего освещения и интерьера. Основной заказчик — производитель светильников Lightstar.

## Цель
Вызвать доверие у B2B-заказчиков (производители, дизайн-студии, интерьерные бренды) и получить заявку на сотрудничество через форму или мессенджер.

## Целевая аудитория
- Маркетологи и владельцы брендов в нише освещения и интерьера
- Дизайн-студии, ищущие SMM-подрядчика
- B2B, решение принимается после изучения портфолио и кейсов

## Тон и стиль
- Элегантный, тёплый, минималистичный
- Без агрессивных продаж — доверие через кейсы и цифры
- Визуально близко к эстетике интерьерных брендов: бежевый, коричневый, тёплые акценты

## Известные решения и договорённости
- JavaScript, не TypeScript — меньше трений для небольшого проекта
- Все тексты хранятся в `src/content/data.js` — легко обновлять без правки компонентов
- Тёмная тема через `next-themes` с `attribute="class"` — нет мигания при загрузке
- Анимации отключаются при `prefers-reduced-motion` через Framer Motion автоматически
